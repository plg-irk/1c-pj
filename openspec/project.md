# Project Context

## Purpose

Новый проект разработки на 1С:Предприятие 8.3.27 для конфигурации, расширений и внешних обработок/отчетов.

## Source Layout

- `src/` contains the main configuration XML dump.
- `ext/` contains configuration extensions.
- `external/epf/` contains external processor sources.
- `external/erf/` contains external report sources.
- `dist/` contains distributable artifacts.
