Справочник "Валюты"

Назначение

Данный справочник используется во всех видах учета для хранения перечня используемых валют, а также их курсов относительно базовой валюты. Справочник относится к разделу Финансы.

По умолчанию в качестве валюты регламентированного учета (базовой валюты) в конфигурации установлен российский рубль.

Реквизиты

  • Цифровой код - уникальный числовой код, принят международным стандартом, служит для идентификации валюты при загрузке курсов из сети Интернет (с сайта РБК).
  • Символьный код - принят международным стандартом, используется как краткое наименование и основное представление валюты.
  • Курс валюты - переключатель может принимать следующие значения:
    • Загружается из Интернета - устанавливается, если валюта может загружаться с сайта РБК.
    • Вводится вручную.
    • Связан с курсом другой валюты - эта возможность может применяться, например, на предприятии для расчета внутреннего курса какой-либо валюты. При этом указывается основная валюта и % наценки - коэффициент, который применяется к курсу основной валюты для вычисления курса текущей валюты.
    • Рассчитывается по формуле - указывается формула расчета.

Графа Курс формы списка элементов справочника содержит значение курса на текущую дату. Обычно это последнее введенное значение валютного курса, получаемое из регистра сведений Курсы валют.
В графе Кратность формы списка задается база сравнения единиц валюты по отношению к одному рублю при расчете валютного курса. Она может отличается от «1», например: 100 иен.

Группы полей вкладки Параметры прописи валюты задают параметры наименования целой и дробной части валюты на русском языке. Эти данные используются в печатных формах документов.

Добавление валюты из Общероссийского классификатора валют (ОКВ)

  • Нажмите кнопку Подобрать из классификатора на форме списка справочника. (Рекомендуется для корректного ввода валюты).
  • Выделив одну или несколько валют, нажмите кнопку Выбрать или воспользуйтесь двойным щелчком мыши по строке валюты для добавления ее в список валют.
  • Следующие поля новой валюты будут заполнены автоматически: Наименование, Символьный код, Цифровой код и флажок Загружается из интернета (если имеется возможность загружать курс этой валюты с сайта РБК).

Ввод валюты не из классификатора (вручную)

  • Нажмите Создать.
  • Заполните сведения о валюте.

Загрузка курсов валют

  • Нажмите кнопку Загрузить курсы валют на форме списка справочника. В результате произойдет вызов обработки Загрузка курсов валют, которая автоматически загружает курсы валют с интернет-сайта www.rbc.ru.
  • Также в программе предусмотрено регламентное задание Загрузка курсов валют для автоматической загрузки курсов валют с сайта РБК.

При использовании в меню дополнительных функций команды Курсы валют открывается табличное поле, содержащее историю изменения курсов данной валюты. Эти значения могут быть введены вручную или загружены с сайта www.rbc.ru.
