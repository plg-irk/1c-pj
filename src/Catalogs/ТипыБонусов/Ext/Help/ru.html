Справочник "Типы бонусов"

Назначение

Справочник содержит в себе информацию о типах бонусов, предоставляемых контрагентам. Используется в договорах взаиморасчетов с контрагентами и при реализации товаров.

Параметры

Длина кода: 8, тип кода: Строка.

Длина наименования: 50.

Иерархический.

Реквизиты

  • Способ вычисления. Реквизит является обязательным для заполнения. Ссылается на перечисление «Способ вычисления». Способ вычисления бонуса (относительная/абсолютная).
  • В валюте договора. Тип значения: «Булево». Истина, если сумма бонуса рассчитывается в валюте договора. Ложь, если сумма расчитывается в произвольной валюте.
  • Валюта начисления. Реквизит является обязательным для заполнения. Ссылается на справочник «Валюты». Валюта для начисления суммы бонуса, используется в случае если признак "В валюте договора" установлен в ложь.
  • Периодичность. Реквизит является обязательным для заполнения. Ссылается на перечисление «Периодичность анализа накопительных скидок». Периодичность выплаты бонуса.

Формы

  • Форма списка. Основная форма выбора группы. Используется для выбора групп.
  • Форма группы. Основная форма группы. Используется для заполнения обязательных реквизитов группы.
  • Форма элемента. Основная форма объекта. Используется для заполнения обязательных реквизитов.
