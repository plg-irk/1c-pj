Справочник "Прайс-Лист"

Назначение

Справочник Прайс-листы предназначен для заполнения и печати произвольных прайс-листов. Прайс-лист - это список товаров, создаваемый для покупателя. Основное назначение прайс-листа - группировка номенклатурных позиций, отвечающая конкретным требованиям пользователя. Набор используемых в информационной базе прайс-листов определяется в справочнике Виды прайс-листов. Кнопка Вид прайс-листа, расположенная на командной панели, дает возможность перейти к прайс-листу другого вида.

Справочник Прайс-листы относится к разделу Продажи.

Кнопка командной панели Показать/скрыть поле расширенной информации выводит или убирает в нижней части окна информационную панель, содержащую вкладки Цены, Партии, Остатки, Цены поставщиков и соответствующие таблицы, которые позволяют дополнить или уточнить параметры прайс-листа, оценить остатки и резервы на складах компании по данным позициям либо по партиям номенклатуры, сравнить цены поставщиков относительно выделенной номенклатуры прайс-листа:

  • Цены. В табличной части отображается информация по выделенной позиции номенклатуры.
    • Тип цен. Ссылается на справочник Типы цен. Типы цен, которые установлены для выделенной позиции номенклатуры.
    • Валюта. Ссылается на справочник Валюты. Валюта, в которой указана цена выделенной позиции номенклатуры.
    • Характеристика. Ссылается на справочник Характеристики номенклатуры. Характеристика выделенной номенклатуры, по которой указана цена.
    • Ед. измерения. Ссылается на справочник Единицы измерения. Единица измерения выделенной позиции номенклатуры.
    • Подразделение. Ссылается на справочник Подразделения компании. Подразделение компании, в котором используется указанная цена на выбранную номенклатуру.
    • Цена. Цена выделенной позиции номенклатуры.
  • Партии. В табличной части отображается информация по выделенной позиции номенклатуры.
    • Партия. Ссылается на документы, по которым были движения выделенной номенклатуры.
    • Остаток партии. Количество остатка выделенной позиции номенклатуры на складе.
    • Себестоимость (упр.). Себестоимость выделенной позиции номенклатуры в валюте управленческого учета.
  • Остатки. В табличной части отображается информация по выделенной позиции номенклатуры.
    • Склад. Ссылается на справочник Склады компании. Склад компании, на который было поступление выделенной позиции номенклатуры.
    • Остаток на складе. Количество товара, которое есть в наличии на указанном складе.
    • Резерв. Количество зарезервированного товара из оставшегося на указанном складе.
    • Сумма розничная. Розничная сумма товара, оставшегося на указанном складе.
  • Цены поставщиков. В табличной части отображается информация по выделенной позиции номенклатуры.
    • Тип цен. Ссылается на справочник Типы цен. Типы цен, которые установлены поставщиком для выделенной позиции номенклатуры.
    • Контрагент. Ссылается на справочник Контрагенты и контакты. Поставщик, у которого приобреталась по указанной цене выделенная позиция номенклатуры.
    • Валюта. Ссылается на справочник Валюты. Валюта, в которой указана цена поставщика выделенной позиции номенклатуры.
    • Цена. Числовое выражения цены выделенной позиции номенклатуры у данного поставщика.

Меню кнопки Заполнение содержит следующие пункты:

  • Подбор. Открывает справочник Номенклатура.
  • Очистить. Очистить все товары. Удаляет все позиции из прайс-листа.
  • Заполнить. Открывает диалоговое окно настройки автозаполнения прайс-листа.
  • Выгрузить. Выгружает прайс-лист в файл заданного формата. Возможны следующие форматы данных для выгрузки прайс-листа:
    • таблицы MS Excel,
    • текстовый файл,
    • через источник данных ADO или файл формата dBase.

Форма настройки автозаполнения прайс-листа, которая открывается пунктом Заполнить меню кнопки Заполнение, содержит следующие поля:

  • Способ заполнения. Предлагает четыре варианта автоматического заполнения прайс-листа:
    • По складским остаткам товаров.
    • По товарам поставщиков.
    • По всей номенклатуре.
    • По существующему прайс-листу.
  • Склад, Дата. Активируются при способе заполнения прайс-листа По складским остаткам товаров. Склад и дата, относительно которых формируется прайс-лист.
  • Поставщик. Активизируется при способе заполнения прайс-листа По товарам поставщиков. Позволяет выбрать поставщика, относительно которого формируется прайс-лист, из справочника Контрагенты и контакты.
  • Группа. Активизируется при способе заполнения прайс-листа По всей номенклатуре. Открывает справочник Номенклатура для выбора группы товаров, которые будут включены в прайс-лист.
  • Прайс-лист. Активизируется при способе заполнения прайс-листа По существующему прайс-листу. Открывает справочник Виды прайс-листов для выбора вида прайс-листа, на основе которого будет сформирован данный прайс-лист.
  • Способ создания групп. Номенклатура в прайс-листе может быть сгруппирована:
    • По видам товаров;
    • По группам товаров;
    • Без создания групп товаров.
  • Очищать прайс-лист перед заполнением. Флажок, устанавливающий требование очистить прайс-лист перед заполнением.
