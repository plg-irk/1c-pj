Документ "Реализация товаров"

Назначение

Документ Реализация товаров служит для отражения в информационной базе факта реализации (отгрузки) товаров и услуг. Этот документ служит также для отражения передачи товаров на реализацию, а также розничной продажи. Вид документа определяется хозяйственной операцией.

При проведении документ формирует хозяйственные операции:

  • Реализация товаров. Хозяйственная операция списывает кредиторскую задолженность компании перед покупателем по другим сделкам, если таковые были, и начисляет дебиторскую задолженность покупателя на регистре Взаиморасчеты компании, уменьшает материальные активы на складах предприятия в виде ТМЦ с собственным или комиссионным признаком партии на регистрах Остатки товаров компании и Партии товаров компании, приходует проданные товары с комиссионным признаком партии на регистр  Реализованные товары (те товары, которые наша компания продала, но не отчиталась перед комитентом), списывает заказы на поставку ТМЦ, сделанные покупателем  по регистрам Заказы покупателей, Заказы распределение и приходует сумму и себестоимость проданных товаров на регистре Продажи.
  • Реализация товаров (комиссия). Хозяйственная операция аналогична операции Реализация товаров за тем исключением, что дебиторская задолженность комиссионеру не начисляется, а начисляется товарная задолженность на регистре Партии товаров отданные, также не приходуется и не регистрируется сумма проданных товаров на соответствующих регистрах.
  • Акт об оказании услуг. Хозяйственная операция списывает кредиторскую задолженность компании перед покупателем по другим сделкам, если таковые были, и начисляет дебиторскую задолженность контрагента по оказанным услугам на регистре Взаиморасчеты компании, стоимость оказанных услуг на регистрах Продажи, Доходы и расходы компании.
  • Реализация агентских услуг. Хозяйственная операция списывает оказание агентских услуг.

Реквизиты

  • Контрагент. Реквизит является обязательным для заполнения. Ссылается на справочник Контрагенты и контакты. Покупатель или комиссионер, которому отгружается товар.
  • Договор. Реквизит является обязательным для заполнения. Ссылается на справочник Договоры взаиморасчетов. Договор, по которому ведутся взаиморасчеты с покупателем или комиссионером.
  • Склад. Реквизит является обязательным для заполнения. Ссылается на справочник Склады компании. Склад компании, с которого продается товар.
  • Ввести счет-фактуру. Если гиперссылка содержит текст «Ввести счет-фактуру», то при переходе по гиперссылке на основании данного документа будет создан счет-фактура выданный. Если счет-фактура был создан ранее, то гиперссылка позволяет открыть соответствующий документ.
  • По договору долг контрагента составляет. Гиперссылка отражает текущее состояние расчетов с контрагентом по договору. Производится переход  к отчету Взаиморасчеты с контрагентами, сформированный для указанного контрагента.

Табличная часть «Товары»

Дополнительные графы

  • % скидки. Процент скидки на сумму с налогами.
  • Сумма списания. Сумма списанной партионной себестоимости. Нередактируемая графа таблицы; появляется при проведении документа.
  • Ячейка. Ссылается на справочник Ячейки хранения. Ячейка хранения товара. Используется для печатных форм документа. 

Данные графы могут быть заполнены автоматически и/или введены вручную. Это зависит от права пользователя на назначение скидки. Если для пользователя установлено право Разрешить выборочное списание партий, то в таблице появится дополнительная колонка Партия.

Кнопка Заполнение, находящаяся над табличной частью документа, позволяет выполнить автозаполнение табличной части по следующим схемам:

  • Очистить табличную часть. Из табличной части будут удалены все позиции.
  • Заполнить складскими остатками. В табличную часть будут выведены все складские остатки товаров.
  • Заполнить остатками по группе номенклатуры. Будет открыто окно, в котором можно будет выбрать группу элементов справочника Номенклатура. В табличную часть будут выведены все имеющиеся в наличии номенклатурные позиции, относящиеся к выбранной группе.
  • Заполнить резервами контрагента. Производит заполнение табличной части документа товарами, находящимися на складах компании и зарезервированных под заказы данного контрагента.
  • Заполнить резервами по заказу. Заполнение резервами по заказу возможно, если документ Реализация товаров введен на основании заказа покупателя. В табличную часть будут помещены все зарезервированные заказом покупателя позиции.
  • Загрузить из ТСД. Вызов обработки загрузки данных с терминала сбора данных.
  • Загрузить из файла. Вызов обработки Загрузка данных из файла.

Подбор номенклатуры в документ можно произвести в обычном режиме, либо по списку товаров, которые заказаны покупателем, используя соответствующие кнопки. Также может быть осуществлен подбор замен.

Ввод на основании

Документ Реализация товаров вводится на основании документов:

  • Заказ покупателя,
  • Счет на оплату,
  • Поступление товаров,
  • Перемещение товаров,
  • Заказ внутренний,
  • Расходный складской ордер,

а также на основании элемента справочника Контрагенты и контакты.

Объекты, вводимые на основании:

  • Возврат от покупателя,
  • Отчет комиссионера,
  • Приходный кассовый ордер,
  • Счет на оплату,
  • Счет фактура выданный,
  • Расходный складской ордер,
  • Переоценка,
  • Чек на оплату,
  • Корректировка движений,
  • Поступление товаров,
  • Жалоба клиента,
  • Корректировка реализации,
  • Отчет комитенту.

Печатные формы

  • Расходная накладная. Простая печатная форма, содержит список отгружаемых товаров покупателю или комиссионеру.
  • Подборочный лист. Простая печатная форма, содержащая помимо самих товаров их ячейки хранения на складе.
  • Форма Торг-12 (Товарная накладная за поставщика). Унифицированная печатная форма № Торг-12, утвержденная постановлением Госкомстата России.
  • Приложение №4 (Транспортная накладная). Правила перевозки грузов автомобильным транспортом.
  • Форма Т-1 (Товарно-транспортная накладная). Унифицированная печатная форма № Т-1, утвержденная постановлением Госкомстата России.
  • Форма М-15 (Накладная на отпуск материалов на сторону).
  • Универсальный передаточный документ.

Журналы, отображающие документ:

  • Покупатели,
  • Складские документы.
