Документ "Разделка"

Назначение

Документ служит для отражения в учете фактов разделки товаров на составляющие. В табличной части документа не могут фигурировать услуги, работы и т.п. Например разделка говяжьих туш на составлющие части, то из одного товара получаем несколько других и отходы.

При проведении документ формирует хозяйственные операции:

  • Разделка. Хозяйственная операция списывает товар из шапки документа с регистров «Остатки товаров компании» и «Партии товаров компании» и приходует товары из табличной части Товары на те же регистры.

Относится к подсистеме: «Управление производством».

Параметры

Длина номера: 10, тип номера: Строка.

Периодичность номера: Год

Тип номера: Строка

Реквизиты

  • Автор. Реквизит является обязательным для заполнения. Ссылается на справочник «Пользователи». Автор документа - пользователь, породивший документ.
  • Организация. Реквизит является обязательным для заполнения. Ссылается на справочник «Организации». Идентификатор юридического лица, от которого выписан документ.
  • Подразделение. Реквизит является обязательным для заполнения. Ссылается на справочник «Подразделения компании». Подразделение компании, в котором был выписан документ.
  • Регламентированный учет. Тип значения: «Булево». Определяет принадлежность к регламентированому учету.
  • Комментарий. Тип значения: «Строка». Произвольный комментарий к документу.
  • Валюта. Реквизит является обязательным для заполнения. Ссылается на справочник «Валюты». Валюта документа.
  • Курс. Реквизит является обязательным для заполнения. Курс валюты документа, на дату документа.
  • Тип Цен. Реквизит является обязательным для заполнения. Ссылается на справочник «Типы цен». Тип Цен, по которым происходит оприходование товаров.
  • Сумма. Тип значения: «Число». Сумма документа.
  • Хоз операция. Реквизит является обязательным для заполнения. Ссылается на справочник «Хоз. операции». Выполняемая документом операция. 
  • Документ основание. Ссылается на документы «Поступление товаров», «Счет на оплату». Документ, на основании которого введен данный, необходим для привязки подчиненных документов к документу основанию, с помощью этого реквизита, затем строится дерево подчиненных документов (по кнопке ).
  • Склад. Ссылается на справочник «Склады (места хранения) компании». Склад компании, на котором будет производиться разделка. 
  • Номенклатура. Реквизит является обязательным для заполнения. Ссылается на справочники «Номенклатура». Разделываемый товар или разукомплектоваемое блюдо.
  • Рецептура. Реквизит является обязательным для заполнения. Ссылается на документы «Рецептура». Рецептура, по которой будет разделываться товар или разукомплектовываться блюдо.
  • Количество. Реквизит является обязательным для заполнения. Тип значения: «Число». Количество разделываемого товара или разукомплектоваемого блюда.
  • Единица измерения. Реквизит является обязательным для заполнения. Ссылается на справочники «Единицы измерения».
  • Коэффициент. Реквизит является обязательным для заполнения. Тип значения: «Число».

Табличная часть «Товары»

  • Номенклатура. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочники «Номенклатура». Получаемые товары.
  • Количество норма. Тип значения: «Число». Количество, котрое должно получиться по рецептуре.
  • Единица измерения. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочники «Единицы измерения». Единица измерения номенклатуры.
  • Коэффициент. Реквизит является обязательным для заполнения. Тип значения: «Число». Коэффициент пересчета по отношению к базовой единице номенклатуры.
  • Цена. Тип значения: «Число». Необходимо в случае операции на розничном складе.
  • Сумма. Тип значения: «Число». Необходимо в случае операции на розничном складе.
  • Ставка НДС. Ссылается на справочники «Ставки НДС». Ставка НДС.
  • Сумма НДС. Тип значения: «Число». Сумма НДС.
  • Характеристика номенклатуры. Реквизит является уникальным. Ссылается на справочники «Характеристики номенклатуры». Характеристика номенклатуры.
  • Всего. Тип значения: «Число». Итоговая сумма по строке документа.
  • Количество фактическое. Реквизит является обязательным для заполнения. Тип значения: «Число». Фактическое количество товара, получившееся в результате операции.
  • Процент выхода. Тип значения: «Число». Реквизит доступен только при операции Разделка.
  • Коэффициент себестоимости. Тип значения: «Число». Коэффициент себестоимости.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора документов данного типа.
  • Форма документа. Основная форма объекта. Используется для заполнения обязательных реквизитов.

Печатные формы

  • Печать этикеток и ценников. Обработка, позволяющая получить печатную форму этикеток и ценников получаемых товаров.

  • ОП-23 (Акт разделки). Унифицированная форма ОП-23 Акт о разделке мяса-сырья на полуфабрикаты.

    Способ вызова

Вызывается из меню "Документы --> Производство --> Разделка".

Движения

  • «Остатки товаров компании». Блок учета остатков товаров компании.
  • «Партии товаров компании». Блок учета партий товаров компании собственных и принятых на комиссию.
