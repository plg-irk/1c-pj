Документ "Рецептура"

Назначение

Документ предназначен для занесения в систему рецептур и норм разделки. Вид документа зависит от операции документа, которая может принимать следующие значения:

  • Рецептура. Используется для формирования рецептуры приготовления продукции.
  • Нормы разделки. Используется для формирования норм разделки товара на ингредиенты.

Параметры

Длина номера: 10, тип номера: Строка.

Периодичность номера: Год

Тип номера: Строка

Объекты, вводимые на основании: «Выпуск продукции».

Реквизиты

  • Автор. Реквизит является обязательным для заполнения. Ссылается на справочник «Пользователи». Автор документа - пользователь, создавший документ..
  • Организация. Реквизит является обязательным для заполнения. Ссылается на справочник «Организации». Юридическое лицо, от которого выписан документ.
  • Подразделение. Реквизит является обязательным для заполнения. Ссылается на справочник «Подразделения компании». Подразделение компании в котором был выписан документ.
  • Комментарий. Тип значения: «Строка». Произвольный комментарий к документу.
  • Валюта. Реквизит является обязательным для заполнения. Ссылается на справочник «Валюты». Валюта документа.
  • Курс. Реквизит является обязательным для заполнения. Тип значения: «Число». Курс валюты документа.
  • Сумма. Тип значения: «Число». Сумма документа.
  • Операция. Реквизит является обязательным для заполнения. Ссылается на справочник «Хоз. операции». Выполняемая документом операция.
  • Продукция. Реквизит является обязательным для заполнения. Ссылается на справочник «Номенклатура». Продукция, для которой собираем ингредиенты.
  • Количество. Реквизит является обязательным для заполнения. Тип значения: «Число». Количество продукции, которое может быть выпущено с указанными ингредиентами.
  • Единица измерения. Реквизит является обязательным для заполнения. Ссылается на справочник «Единицы измерения». Единица измерения выпускаемой продукции.
  • Основная рецептура. Тип значения: «Булево». Признак основной рецептуры данной продукции. Основная рецептура может быть только одна.
  • Технология производства. Тип значения: «Строка». Технология производства.
  • Оценка качества. Тип значения: «Строка». Оценка качества.
  • Вкус. Тип значения: «Строка». Вкус.
  • Консистенция. Тип значения: «Строка». Консистенция.

Табличная часть «Товары»

  • Номенклатура. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник «Номенклатура». Номенклатура (товар,услуга и т.п.).
  • Количество бруто. Реквизит является обязательным для заполнения. Тип значения: «Число». Количество брутто единиц измерения номенклатуры.
  • Количество нетто. Тип значения: «Число». Количество нетто.
  • Единица измерения. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник «Единицы измерения». Единица измерения номенклатурной позиции.
  • Коэффициент себестоимости. Тип значения: «Число». Коэффициент себестоимости.
  • Разрешить замены. Тип значения: «Булево». Если флажок установлен, то по данному ингредиенту разрешается замена на аналоги.
  • Разрешить недовложения. Тип значения: «Булево». Если флажок установлен, то разрешается выпускать продукцию при нехватке данного ингредиента.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора документов данного типа.
  • Форма документа. Основная форма объекта. Используется для заполнения обязательных реквизитов.

Способ вызова

Вызывается из меню "Документы -- Производство -- Рецептура"
