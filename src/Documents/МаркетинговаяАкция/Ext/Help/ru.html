Документ "Назначение скидок"

Назначение

Предназначен для установки или отмены действующих скидок/наценок.

При проведении документ формирует хозяйственные операции:

  • Установка скидки. Хозяйственная операция регистрирует установку скидки в регистре сведений «Скидки».
  • Отмена скидки. Хозяйственная операция регистрирует отмену скидки в регистре сведений «Скидки».

 

Параметры

Длина номера: 10, тип номера: Строка.

Периодичность номера: Год

Тип номера: Строка

Реквизиты

  • Автор. Реквизит является обязательным для заполнения. Ссылается на справочник «Пользователи». Автор документа - пользователь, породивший документ.
  • Организация. Реквизит является обязательным для заполнения. Ссылается на справочник «Организации». Идентификатор юридического лица, от которого выписан документ.
  • Подразделение. Реквизит является обязательным для заполнения. Ссылается на справочник «Подразделения компании». Подразделение компании, в котором был выписан документ.
  • Комментарий. Произвольный комментарий к документу.
  • Валюта. Реквизит является обязательным для заполнения. Ссылается на справочник «Валюты». Валюта документа.
  • Курс. Реквизит является обязательным для заполнения. Курс валюты документа.
  • Хозяйственная операция. Реквизит является обязательным для заполнения. Ссылается на справочник «Хоз. операции». Выполняемая документом операция.

Табличная часть «Скидки»

  • Скидка. Реквизит является обязательным для заполнения. Ссылается на справочник «Типы скидок».
  • Флаг вытеснения. Истина - скидка вытесняющая, Ложь - скидка может использоваться соместно.
  • Размер. Реквизит является обязательным для заполнения. Процент скидки для относительных скидок или сумма скидки для абсолютных скидок
  • Способ вычисления. Реквизит является обязательным для заполнения. Способ вычисления скидки, абсолютный или отностиельный.
  • Номенклатура. Ссылается на справочник «Номенклатура». Товар или группа на которую назначается скидка
  • Тип номенклатуры. Ссылается на справочник «ТипыНоменклатуры». Тип номенклатуры, на который назначается скидка.
  • Договор. Ссылается на справочник «ДоговорыВзаиморасчетов». Договор, на который назначается скидка.
  • Свойство.
  • Количество. Количество, начиная с которого предоставляется скидка.
  • Правило. Правило расчета скидки по количеству.
  • Сумма чека. Сумма чека, начиная с которой применяется скидка.
  • Сумма строки. Сумма строки, начиная с которой применяется скидка.
  • Дисконтная карта. Ссылается на справочник «Карточки». Дисконтная карта на которую назначается скидка.
  • Сумма накопления. Сумма накопления на карте. Применяется совместно с дисконтной картой.
  • Дата. Период действия скидки.
  • Время. Время действия скидки.
  • Дни недели. Дни недели в которые действует скидка (Маска дней недели 0/1).
  • Прайс-лист. Прайс-лист подарка
  • Сумма подарка. Максимальная сумма подарка.
  • Склад. Ссылается на справочник «СкладыКомпании». Склад/Отдел.

Табличная часть «Подразделения»

  • Подразделение компании. Реквизит является обязательным для заполнения. Ссылается на справочник «Подразделения компании». Подразделения компании, в которых будет установлена или отменена скидка в зависимости от выбранной хозоперации.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора документов данного типа.
  • Форма документа. Основная форма документа. Используется для заполнения обязательных реквизитов.

Печатные формы

  • Накладная. Простая печатная форма, содержит список устанавливаемых скидок.

Способ вызова

Вызывается из меню "Документы --> Ценообразование --> Назначение  скидок".

Движения

  • Регистр сведений «Скидки».
