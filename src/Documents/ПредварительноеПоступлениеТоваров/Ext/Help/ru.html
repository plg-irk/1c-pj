Документ "Предварительное поступление товаров"

Назначение

Поступление номенклатурных позиций в результате закупки и поступление на комиссию в конфигурации оформляется одним документом. В табличной части документа не могут фигурировать услуги, работы и т.п. Вид поступления определяется хозяйственной операцией документа.

Документ не проводится, является регистрационным.

 

Параметры

Длина номера: 10, тип номера: Строка.

Периодичность номера: Год

Тип номера: Строка

Вводится на основании: «Заказ поставщику».

Объекты, вводимые на основании: «Возврат поставщику», «Заказ внутренний», «Заказ покупателя», «Заказ поставщику», «Изменение цен», «Перемещение товаров», «Платежное поручение», «Поступление дополнительных расходов», «Расходный кассовый ордер», «Реализация товаров», «Счет на оплату», «Счет фактура полученный».

Реквизиты

  • Автор. Реквизит является обязательным для заполнения. Ссылается на справочник «Пользователи». Автор документа - пользователь, породивший документ.
  • Организация. Реквизит является обязательным для заполнения. Ссылается на справочник «Организации». Идентификатор юридического лица, от которого выписан документ.
  • Подразделение. Реквизит является обязательным для заполнения. Ссылается на справочник «Подразделения компании». Подразделение компании, в котором был выписан документ.
  • Комментарий. Произвольный комментарий к документу.
  • Регламентированный учет. Тип значения: «Булево». Флаг отражения документа в регламентированном учете. 
  • Контрагент. Реквизит является обязательным для заполнения. Ссылается на справочник «Контрагенты». Поставщик/комитент от которого мы получили товар.
  • Валюта. Реквизит является обязательным для заполнения. Ссылается на справочник «Валюты». Валюта документа.
  • Курс. Реквизит является обязательным для заполнения. Курс валюты документа.
  • Склад. Реквизит является обязательным для заполнения. Ссылается на справочник «Склады (места хранения) компании». Склад компании, на который поступают товары.
  • Документ основание. Ссылается на документ «Заказ поставщику». Документ, на основании которого введен данный, необходим для привязки подчиненных документов к документу основанию, с помощью этого реквизита, затем строится дерево подчиненных документов (по кнопке ).
  • Тип Цен. Реквизит является обязательным для заполнения. Ссылается на справочник «Типы цен». Тип цен закупки.
  • Номер входящего документа. Номер входящего документа, используется для отражения номера бумажного документа, т.к. номер полученного документа может отличаться от нашего внутреннего номера системы, а также при формировании печатной формы.
  • Дата входящего документа. Дата входящего документа, используется для отражения даты бумажного документа, т.к. дата полученного документа может отличаться от даты регистрации документа в нашей системе, а также при формировании печатной формы.
  • Сумма. Сумма документа.
  • Хозяйственная операция. Реквизит является обязательным для заполнения. Ссылается на справочник «Хоз. операции». Выполняемая документом операция.

Табличная часть «Товары»

  • Номенклатура. Реквизит является уникальным и обязательным для заполнения. Ссылается на справочник «Номенклатура». Номенклатура (товар).
  • Количество. Реквизит является обязательным для заполнения. Количество единиц измерения номенклатуры.
  • Единица измерения. Реквизит является обязательным для заполнения. Ссылается на справочник «Единицы измерения». Единица измерения номенклатурной позиции.
  • Коэффициент. Реквизит является обязательным для заполнения. Коэффициент пересчета по отношению к базовой единице номенклатуры.
  • Количество базовое. Количество номенклатуры в базовых единицах (коэффициент=1).
  • Цена. Цена номенклатурной позиции.
  • Сумма. Сумма всегда без скидки. НДС входит в сумму если это указано в типе цен. Сумма всегда равна Цена*Количество.
  • Характеристика номенклатуры. Реквизит является уникальным. Ссылается на справочник «Характеристики номенклатуры». Характеристика/серия номенклатуры, например, цвет, размер и т.п. 
  • Всего. Итоговая сумма по строке документа со всеми налогами.
  • Ставка НДС. Ссылается на справочник «Ставки НДС». Ставка НДС по номенклатурной позиции.
  • Сумма НДС. Сумма НДС по номенклатурной позиции.
  • ГТД. Ссылается на справочник «ГТД». Номер грузовой таможенной декларации (для товаров поступивших по импорту).
  • Процент наценки. Наценка на закупочную цену для вычисления розничной цены.
  • Цена розничная. Розничная цена для оприходования номенклатуры на розничный склад.
  • Сумма розничная. Розничная сумма для оприходвания номенклатуры на розничный склад.

Формы

  • Форма списка. Основная форма списка и выбора. Используется для отображения списка или выбора документов данного типа.
  • Форма документа. Основная форма документа. Используется для заполнения обязательных реквизитов.

Печатные формы

  • Акт расхождения. Простая печатная форма, отображает разницу между заказанными товарами и фактически полученными.

Способ вызова

Вызывается из меню "Документы --> Поступление ТМЦ --> Предварииельное поступление товаров".

Журналы отображаемые документ: «Поставщики».
