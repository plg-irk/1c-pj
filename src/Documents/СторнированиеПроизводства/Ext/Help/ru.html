Документ "Сторнирование производства"

Назначение

Документ предназначен для отражения в учете операций по сторнированию по выпуска продукции, вложенного выпуска полуфабрикатов, списания полуфабрикатов и ингредиентов. Относится к подсистеме: «Управление выпуском готовой продукции». В связи с тем, что целесообразность применения данного документа находится под большим сомнением, рекомендуется использовать его только в случае крайней необходимости.

Способ вызова

Вызывается из меню "Документы -> Производство -> Сторнирование производства".
