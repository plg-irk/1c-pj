Отчет "Анализ устойчивости ассортимента"

Назначение

1. коэффициент устойчивости ассортимента марки считается следующим образом:
                                        Сумм(О1+О2+О3+....Оn)
                      Ку=1 -       --------- ;
                                        n * a
где Ку – коэффициент устойчивости ассортимента товаров в определенном периоде;
О1;О2;...Оn – количество разновидностей товаров отсутствующих в продаже в момент проверок (из предусмотренных разработанным ассортиментным перечнем товаров);
a - количество разновидностей товаров, предусмотренных разработанным ассортиментным перечнем; (тоесть сколько в списке вообще товаров на складе)
n - количество проверок. (дней в периоде)

Оптимальное значение коэффициента устойчивости ассортимента товаров в магазине на протяжении квартала должно быть не ниже
-        для универсамов и гастрономов - 0,90;
-        для универмагов - 0,80;
-        для магазинов обуви и одежды - 0,75;
-        для магазинов по продаже культтоваров, спортивных, хозяйственных, галантерейных товаров - 0,85.

2. Коэффициент присутствия марки. Длительность присутствия марки на остатках склада. Если была каждый день анализа - то 100% присутствия, Если была только в половине дней - то значит 50%.

 

Формы

  • Аанлиз устойчивости ассортимента. Основная форма настроек формирования отчета.
