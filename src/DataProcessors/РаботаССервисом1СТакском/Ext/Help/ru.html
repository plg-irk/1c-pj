В обработке демонстрируется работа с сервисом 1С-Такском.

Получение идентификатора абонента и переход в личный кабинет

  • Сертификат электронной подписи - сертификат абонента электронного документооборота, который будет связан с полученным идентификатором абонента.
  • Организация - используется для заполнения данных в заявке на получение идентификатора абонента (см. метод ЗаполнитьРегистрационныеДанныеОрганизации() общего модуля Подключение1СТакскомПереопределяемый).
  • Получить уникальный идентификатор абонента - начинает процесс получения идентификатора. Полученный идентификатор заполняется в поле "Уникальный идентификатор абонента". Для выполнения поле "Сертификат электронной подписи" должно быть обязательно заполнено.
  • Открыть личный кабинет абонента - открывает личный кабинет абонента электронного документооборота. Для выполнения поле "Сертификат электронной подписи" должно быть обязательно заполнено.

 

Поле "Уникальный идентификатор абонента"

В данном поле заполняется полученный идентификатор абонента. Значение поля также определяет абонента, для которого регистрируется новый сертификат (см. "Регистрация нового сертификата абонента").

 

Регистрация нового сертификата абонента

  • Сертификат электронной подписи - регистрируемый сертификат абонента электронного документооборота.
  • Организация - используется для заполнения данных в заявке на регистрацию нового сертификата абонента (см. метод ЗаполнитьРегистрационныеДанныеОрганизации() общего модуля Подключение1СТакскомПереопределяемый).
  • Зарегистрировать сертификат абонента - начинает процесс регистрации сертификата. Для выполнения поле "Уникальный идентификатор абонента" должно быть заполнено, т.к. значение данного поля определяет абонента, для которого регистрируется сертификат.
