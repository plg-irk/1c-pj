Форма «Расширение прав доступа»

Назначение

Используется для настройки расширения прав доступа в разрезе видов документов.

В перечень добавляются документы, по которым необходима установка значений прав/настроек, отличных от стандартных, устанавливаются значения прав/настроек.

С помощью кнопки командной панели «По текущей строке» можно установить значение, выбранное в текущей строке, для всех документов в списке.

Способ вызова

Вызывается двойным щелчком левой кнопкой мыши в колонке «Расширение прав» дерева прав и настроек в основной форме (доступно только для прав и настроек, отмеченных галочкой )
