Обработка "Персональные настройки"

Назначение

Обработка используется для организации работы с группами доступа, а также со всеми правами и настройками пользователей и групп доступа. Также на форме производится настройка расширения прав доступа для определенных прав и настроек, настройка пользователей с персональными группами доступа и настройка использования утверждения документов.

Формы

  • Персональные настройки. Основная форма обработки. Закладки формы:
    • Права и настройки. Установка значений прав и настроек пользователя/группы доступа (права обозначены в таблице пиктограммой красного цвета, настройки - зелёного).

      Если выбрана группа доступа - разрешено менять как права, так и настройки. Все значения будут установлены для пользователей, принадлежащих данной группе доступа.
      Если выбран пользователь, то он может менять только свои настройки, права устанавливаются из его группы доступа. К группе доступа пользователя можно перейти кнопкой  «Открыть группу пользователя».

      Для удобства редактирования в командной панели реализован фильтр, позволяющий переключать отображение только прав, только настроек или прав и настроек одновременно.

      Форма настройки расширения прав доступа в разрезе видов документов вызывается двойным щелчком левой кнопкой мыши в колонке «Расширение прав» (доступно только для прав и настроек, отмеченных галочкой ).

      На странице доступен поиск прав и настроек как по коду, так и по наименованию или его фрагменту.

    • Профили доступа. Настройка списка используемых в группе доступа профилей, а также настройка значений видов доступа (доступно только для групп доступа).

      В дереве профилей галочками отмечаются доступные для выбранной группы доступа профили, там же доступен иерархический просмотр ролей, разрешенных для каждого профиля.

      В табличных полях в правой части страницы производится настройка видов и значений доступа, у которых в профиле установлено значение «Все разрешены, исключения назначаются в группах доступа» либо «Все запрещены, исключения назначаются в группах доступа». В верхнем табличном поле производится выбор значения доступа («Все разрешены» или «Все запрещены»), в нижнем формируется список исключений из этого правила доступа.

      На странице доступен поиск профилей и ролей по наименованию или его фрагменту.

    • Участники. Настройка списка пользователей данной группы доступа (доступно только для групп доступа).

      Доступен подбор либо стандартное добавление и удаление участников группы доступа. Пользователь может входить только в одну группу доступа.

    • Утверждение документов. Настройка использования механизма утверждения документов для пользователей группы (доступно только для групп доступа).

      Вначале необходимо добавить документы, утверждение которых будет контролироваться, в список используемых. Для этого нужно нажать кнопку «Настроить использование утверждения» и добавить документы в открывшейся форме списка регистра сведений «Использовать утверждение документов».

      Там же для каждого документа можно настроить поведение при отмене проведения документа галочкой «Отклонение при отмене проведения». Если она установлена, у документа при отмене проведения будет установлен статус "Отклонён", иначе, если сброшена - "Согласован".

      Для добавленных документов по двойному щелчку левой кнопкой мыши в списке выбираются доступные статусы утверждения. Статус «Подготовлен» доступен для всех документов по умолчанию. Статусы «Согласован» и «Утвержден» активируются согласно полномочий пользователя/группы доступа. Статус «Отклонен» разрешается автоматически, если доступен хотя бы один из статусов «Согласован» или «Утвержден».

      Также можно выбрать несколько или все документы в списке и, выбрав в контекстном меню табличного поля (вызывается щелчком правой кнопкой мыши) пункт «Установить статус выделенных документов», настроить доступные статусы одновременно для всех выделенных документов.

  • Расширение прав доступа. Используется для настройки расширения прав доступа в разрезе видов документов.

    В перечень добавляются документы, по которым необходима установка значений прав/настроек, отличных от стандартных, устанавливаются значения прав/настроек.

    С помощью кнопки командной панели «По текущей строке» можно установить значение, выбранное в текущей строке, для всех документов в списке.

  • Настройка печати. Используется для настройки параметров печати перечня прав и настроек.

    Доступны 2 режима печати: печать прав и настроек для пользователей или для групп доступа. Также предусмотрены следующие настройки (фильтры) для данных, выводимых на печатную форму: отображать права, отображать настройки, показывать значения по умолчанию и описания прав и настроек.

    Вызывается кнопкой командной панели «Печать» в основной форме обработки.

Способ вызова

Вызывается из форм списка справочников «Группы доступа», «Пользователи» кнопкой  «Права и настройки».

Печатные формы

  • Права и настройки пользователей. Печать перечня прав и настроек пользователей или групп доступа.

    Перед печатью вызывается форма настроек печати.
